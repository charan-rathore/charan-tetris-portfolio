# Typography

Chakra Petch by Cadson Demak gives the main interface a readable, squared silhouette. It is hosted locally in regular and semibold weights under the SIL Open Font License. Press Start 2P remains a small arcade accent; Geist Mono is reserved for code and measurements. The original cream project artwork sits in a dark, warm-edged illustration frame rather than being recolored.

Source: https://github.com/google/fonts/tree/main/ofl/chakrapetch
