# Progressive context dial

Only three outer interests are shown initially. A visitor follows a project,
its approach, its result and its evidence; only the current neighborhood is
rendered. Breadcrumbs preserve the chosen path. Neighborhoods paginate at four
choices, with an equivalent reading list and no hidden future-layer previews.
Edge width represents curated story importance (1–3), never a fabricated score.
Technology names remain attached to the project's explanation rather than
becoming context-free shared nodes.

Body and display typography uses Oxanium by Severin Meyer, downloaded from the
Google Fonts source distribution. The local font and SIL Open Font License are
in src/app/fonts. Press Start 2P remains the arcade accent font; Geist Mono is
retained for compact numeric and code text.

Validation: 11 tests, production build, targeted ESLint, and actual Brave
traversal from interest through evidence; weighted edges, breadcrumb reset,
pagination, reading view, mobile overlap and 44px targets all pass.
